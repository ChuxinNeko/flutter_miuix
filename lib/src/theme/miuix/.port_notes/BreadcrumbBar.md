## 平台/原生差异处理(platformConcerns)
No true native features (no blur/sensors/haptics). Concerns are all layout-timing / animation-fidelity: (1) Compose onGloballyPositioned + positionInRoot() has no direct Flutter analogue — must measure the highlighted segment's RenderBox after a frame (GlobalKey + WidgetsBinding.instance.addPostFrameCallback), so initial auto-center happens one frame after first layout, exactly like Compose's `positioned`-gated effect. (2) Compose ScrollState.animateScrollTo uses a default spring (no-bounce, ~medium stiffness); closest Flutter is ScrollController.animateTo with a decelerate curve/duration OR a physics AnimationController driven by folmeSpring(damping:1.0). (3) LocalIndication material ripple → use GestureDetector (miuix mobile style has no ripple) or MiuixPressable; do NOT add Material InkWell ripple. (4) graphicsLayer scaleX=-1 RTL flip of the arrow → wrap the chevron painter in Transform.scale(scaleX: Directionality.of(context)==TextDirection.rtl ? -1 : 1) with alignment center.

## 实现要点(keyNotes) — 严格按此复刻
FILE: components/miuix_breadcrumb_bar.dart. No unported-component deps — portable immediately. The arrow separator is an INLINE ImageVector (MiuixIcons.Basic.ArrowRight), NOT the miuix Icon component; reproduce it with a CustomPainter, do not depend on any Icon widget.

STRUCTURE = SingleChildScrollView(scrollDirection: Axis.horizontal, controller:) -> Padding(insideMargin) -> Row(crossAxisAlignment: center). Padding is INSIDE the scroll view (Compose order .horizontalScroll().padding()) so the margin scrolls with content. Build children by iterating items; for index>0 prepend a separator before the segment.

DEFAULTS (verbatim, dp->logical px): InsideMargin = EdgeInsets.symmetric(horizontal:12, vertical:8). ItemHeight = 32. ItemHorizontalPadding = 10 (internal text padding, symmetric horizontal). ItemMaxWidth = 160 (default; caller-overridable). Separator: EdgeInsets.symmetric(horizontal:4), fixed size width:10 height:16.

SEGMENT (private _BreadcrumbSegment): SizedBox(height:32) + ConstrainedBox(maxWidth: itemMaxWidth); shape is Compose CircleShape on a 32-tall box = STADIUM/pill (fully rounded ends, radius = height/2 = 16) — use StadiumBorder or BorderRadius.circular(16). Fill background first, then EdgeInsets.symmetric(horizontal:10) inside, then centered text. Text via MiuixText: fontSize = MiuixTheme.of(context).textStyles.body2.fontSize, fontWeight = highlighted ? FontWeight.w500 (Medium) : FontWeight.w400 (Normal), maxLines:1, overflow: TextOverflow.ellipsis, color = textColor. Wrap tap in GestureDetector(onTap: enabled ? onClick : null, behavior: HitTestBehavior.opaque); gate by enabled.

COLOR SELECTION per segment: if(!enabled){bg=disabledBackgroundColor; text=disabledColor} else if(highlighted){bg=highlightBackgroundColor; text=highlightColor} else {bg=backgroundColor; text=color}. Separator tint = enabled ? separatorColor : disabledColor.

COLORS DEFAULTS (defaultColors(context), use color.withValues(alpha:...) not deprecated withOpacity): color = onBackground.withValues(alpha:0.55); highlightColor = primary; disabledColor = disabledOnSecondaryVariant; separatorColor = onSurfaceVariantActions; backgroundColor = onBackground.withValues(alpha:0.1); highlightBackgroundColor = primary.withValues(alpha:0.2); disabledBackgroundColor = disabledSecondaryVariant. All tokens exist in MiuixColors — none new.

CHEVRON PAINTER (viewBox 10x16, PathFillType.evenOdd, fill=separator color): reproduce path exactly then fill. Path: moveTo(1.65,1.469); cubicTo(1.929,1.19, 2.381,1.19, 2.66,1.469); lineTo(8.721,7.53); cubicTo(9.0,7.809, 9.0,8.261, 8.721,8.54); lineTo(2.66,14.601); cubicTo(2.381,14.88, 1.929,14.88, 1.65,14.601); cubicTo(1.371,14.322, 1.371,13.87, 1.65,13.591); lineTo(7.205,8.035); lineTo(1.65,2.479); cubicTo(1.371,2.2, 1.371,1.748, 1.65,1.469); close(). Set path.fillType = PathFillType.evenOdd; canvas.drawPath(path, Paint()..color=tint). Rendered at 10x16 (1:1 with viewBox, no scaling). RTL: Transform.scale(scaleX:-1) when Directionality.rtl.

AUTO-CENTER LOGIC (StatefulWidget, GlobalKey on highlighted segment): hasHighlight = highlightIndex >= 0. Pass highlightIndex<0 (e.g. -1) to disable highlight AND auto-scroll. Centering target: targetScroll = itemContentX - (viewportWidth - itemWidth)/2, clamped to [0, maxScrollExtent]. Obtain measurements in Flutter after a post-frame callback: viewportWidth = controller.position.viewportDimension; maxScrollExtent = controller.position.maxScrollExtent; itemWidth = segmentRenderBox.size.width; itemContentX (left edge in scroll-content space) = controller.offset + (segmentBox.localToGlobal(Offset.zero).dx - viewportRenderBox.localToGlobal(Offset.zero).dx). (This is the correct content-relative form of Compose's positionInRoot().x + scrollState.value.) TWO triggers, mirroring the two LaunchedEffects: (a) on FIRST layout/positioning -> controller.jumpTo(target) INSTANT (Compose scrollTo). (b) on highlightIndex CHANGE (didUpdateWidget) -> ANIMATED (Compose animateScrollTo): controller.animateTo(target, duration: ~Duration(milliseconds:250), curve: MiuixMotion.standardDecelerate) or drive an AnimationController with folmeSpring(damping:1.0, response:~0.25). Guard all with hasHighlight, viewportWidth>0, itemWidth>0, controller.hasClients. Create internal ScrollController when scrollController param is null; dispose only the internally-created one.

CONSTRUCTOR PARAMS to expose: items (required), onItemClick(int) (required), highlightIndex (default items.length-1 / lastIndex), enabled (default true), colors (default defaultColors), insideMargin, itemMaxWidth, scrollController (nullable), plus optionally onLongPress not present. No interactionSource/indication equivalents needed (handled by GestureDetector).
