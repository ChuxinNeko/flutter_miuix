- 预估行数: 640
- 未移植依赖(unportedDeps): MiuixPopupUtils, ListPopup
- 已移植依赖(portedDeps): MiuixSquircleBorder, MiuixContentColor, MiuixTheme, MiuixText, MiuixTextButton, MiuixButtonColors, folmeSpring, MiuixMotion

## 平台/原生差异处理(platformConcerns)
Compose `Popup` + `PopupPositionProvider` -> Flutter `Overlay`+`OverlayEntry` (or `OverlayPortal`). No CompositedTransformFollower — the flip/clamp logic needs a custom positioning delegate that reads the anchor's window rect (via GlobalKey/RenderBox `localToGlobal`) and the tooltip's measured size, then computes offset exactly like TooltipPopupPositionProvider (see keyNotes). Mouse hover -> `MouseRegion(onEnter/onExit)`; onEnter shows, onExit dismisses only when NOT persistent. Long-press (touch/stylus) -> `GestureDetector(onLongPress:)` using Flutter's `kLongPressTimeout` (500ms); the Kotlin code consumes the following up-event so the anchor's own tap doesn't fire — replicate by having the long-press win the gesture arena / not forwarding the tap. Global single-tooltip behavior (MutatorMutex.GlobalMutatorMutex) -> a static/global reference to the active MiuixTooltipState; calling show() dismisses the previously active one. Auto-dismiss timeout (non-persistent) -> a `Timer` of BasicTooltipDefaults.TooltipDuration = 1500ms started on show, cancelled on manual dismiss; persistent tooltips skip the timer. focusable=true (rich) -> the overlay needs a full-screen tap-catcher barrier that dismisses on outside tap and lets cursor travel onto the tooltip; focusable=false (plain) -> no barrier, no outside-tap dismiss. Compose `dropShadow` (Shadow radius=10dp, black, alpha 0.1) -> `BoxShadow(color: Colors.black.withOpacity(0.1), blurRadius: 10)` on a RoundedRectangle; note the shadow uses a plain RoundedCornerShape(cornerRadius) while the fill uses squircleBackground — acceptable to shadow the squircle path directly. Semantics (liveRegion/paneTitle/onLongClick) -> Flutter `Semantics(liveRegion:true, label:..., onLongPress:...)`, low priority for fidelity.

## 实现要点(keyNotes) — 严格按此复刻
DEFAULTS (verbatim, dp=logical px). SpacingBetweenTooltipAndAnchor=8. caretSize = width 16 x height 8. PlainTooltipMaxWidth=200; PlainTooltipCornerRadius=12; PlainTooltipInsideMargin = EdgeInsets.symmetric(horizontal:12, vertical:8). Plain container=colorScheme.onSecondaryVariant, content=colorScheme.secondaryVariant (inverse surface). Plain text uses textStyles.body2, maxLines:2, overflow ellipsis. RichTooltipMaxWidth=320; RichTooltipCornerRadius=16; RichTooltipInsideMargin=EdgeInsets.all(16). RichTooltipActionCornerRadius=8; RichTooltipActionInsideMargin=EdgeInsets.symmetric(horizontal:12, vertical:6). Rich colors: container=surfaceContainer, content=onSurfaceContainerVariant, title=onSurfaceContainer, action=primary. Rich body text=textStyles.body2; rich title=textStyles.subtitle. Rich layout = Column with 8dp vertical spacing between title/body/action; action wrapped in a Box aligned to End (right). Rich action button is a MiuixTextButton with transparent container, textColor=actionContentColor, minWidth:0, minHeight:0, cornerRadius:8, insideMargin=(h:12,v:6); on click invoke onActionClick then state.dismiss().

PERSISTENCE: plain default isPersistent=false (auto-dismiss after 1500ms via timer), rich default isPersistent=true (stays until outside tap / back / action). Default positioning = Below.

ANIMATIONS (enter/exit wrap the tooltip content; transformOrigin = center 0.5,0.5). Enter = fadeIn + scaleIn(from 0.9). fade enter = tween 200ms with Compose default easing (Curves.fastOutSlowIn). scale enter spring: dampingRatio=0.82, stiffness=362.5 -> folmeSpring(damping:0.82, response:0.33). Exit = fadeOut + scaleOut(to 0.9). fade exit = tween 150ms, Curves.fastOutSlowIn. scale exit spring (TooltipExitScaleSpec): DampingRatioNoBouncy=1.0, StiffnessMedium=1500 -> folmeSpring(damping:1.0, response:0.1622). Implement via AnimationController driving both a fade (opacity) and a scale; use spring for scale so an interrupted enter reverses smoothly (Kotlin note: must not hard-cut). Keep tooltip mounted while target=true OR still animating (mirror isVisible = targetState || !isIdle). NOTE: the ListPopupDefaults.AlphaEnter/Exit + FractionAnimationSpec are just these constants — inline them; ListPopup itself need not be ported first. MiuixPopupUtils is the only hard ordering dependency.

CARET: default caretShape=null => NO caret (Miuix caret-less is the default look). Caret drawn only when caretShape!=null AND positioning is Above or Below. caretOnTop = (positioning==Below). Draw in a CustomPainter behind the surface: anchorCenterX = anchorGlobalRect.left + anchorRect.width/2; selfX = tooltipGlobalRect.left; caretHalf = 8 (caretSize.width/2); cr = cornerRadius(px); centerX = (anchorCenterX - selfX).clamp(cr+8, tooltipWidth - cr - 8); caretHeight=8. If caretOnTop: triangle path (centerX,0)->(centerX-8,8)->(centerX+8,8) close. Else: (centerX,H)->(centerX-8,H-8)->(centerX+8,H-8) close. Fill with containerColor. When caret is drawn, add inner padding top=8 (if caretOnTop) or bottom=8 (else) so content clears the caret. The standalone TooltipCaretShape (for TooltipDefaults.caretShape()) is a downward-ish triangle: moveTo(w/2,0)->(0,h)->(w,h) close.

SURFACE STACK (outer->inner): Box widthIn(max: maxWidth) [measure self bounds] -> optional caret painter behind -> inner Box with padding(top/bottom for caret) -> dropShadow(RoundedRect cornerRadius, black@0.1, blur10) -> squircleBackground(containerColor, cornerRadius) -> padding(insideMargin) -> content. Use ShapeDecoration with MiuixSquircleBorder(cornerRadius:, enabled: cornerRadius>0) for the fill.

POSITION PROVIDER (flip + clamp), spacing default 8px. Cross-axis center: cx = anchor.left + (anchor.width - popupW)/2; cy = anchor.top + (anchor.height - popupH)/2. Resolve Start/End by text direction: Start->Left(LTR)/Right(RTL), End->Right(LTR)/Left(RTL). Below: below=anchor.bottom+spacing; above=anchor.top-popupH-spacing; y = (below+popupH <= winH || above<0) ? below : above; x=cx. Above: above=anchor.top-popupH-spacing; below=anchor.bottom+spacing; y = (above>=0 || below+popupH>winH) ? above : below; x=cx. Left: left=anchor.left-popupW-spacing; right=anchor.right+spacing; x = (left>=0 || right+popupW>winW) ? left : right; y=cy. Right: right=anchor.right+spacing; left=anchor.left-popupW-spacing; x = (right+popupW<=winW || left<0) ? right : left; y=cy. Final clamp: x=x.clamp(0, max(0, winW-popupW)); y=y.clamp(0, max(0, winH-popupH)).

GESTURES: touch/stylus long-press (500ms) -> show(UserInput priority) and swallow the up so anchor onTap doesn't also fire. Mouse enter -> show; mouse exit -> dismiss only if !isPersistent (lets cursor travel onto a persistent rich tooltip). enableUserInput=false disables both. State: transition target true/false; dismiss sets target=false (and cancels the job/timer if persistent). onDispose cancels timer/job. Only one tooltip visible globally at a time.
