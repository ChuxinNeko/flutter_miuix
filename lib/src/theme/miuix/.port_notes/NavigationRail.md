## 实现要点(keyNotes) — 严格按此复刻
TWO layout modes selected via an InheritedWidget (LocalNavigationRailExpandInfo → e.g. _NavRailExpandInfo InheritedWidget carrying `Animation<double> progress` + `double collapsedWidth`). NavigationRail provides it ONLY when state != null; otherwise items render the classic collapsed layout.

DIMENSIONS (NavigationRailDefaults, dp→logical px): MinWidth=80, ExpandedWidth=240, VerticalPadding=24 (Column vertical padding), HeaderSpacing=24 (Spacer after toggle and after header), IconSize=28, IconTextSpacing=4 (collapsed icon↔label), ItemVerticalPadding=12, LabelFontSize=12, ExpandedLabelFontSize=16, ExpandedItemHorizontalMargin=12, ExpandedItemCornerRadius=16, CollapsedIndicatorVerticalPadding=4, ExpandedItemContentHorizontalPadding=14, ExpandedItemContentVerticalPadding=14, ExpandedItemIconTextSpacing=16. ExpandContentDescription="Expand navigation rail", CollapseContentDescription="Collapse navigation rail".

ANIMATION: single AnimationController driven by SpringDescription = folmeSpring(damping:1.0, response:0.35); target 1.0 when expanded else 0.0; animateWith on an unbounded controller (or SpringSimulation). One shared `Animation<double> progress` (clamp 0..1) feeds width + every item's morph + toggle position + label fontSize. Use AnimatedBuilder around the layout so frames re-layout without full rebuild — mirror the Compose intent (progress read in layout phase) but AnimatedBuilder rebuild is acceptable.

RAIL WIDTH: outer Row fillMaxHeight + background(color=colors.surface default) painted BEFORE insets padding. Inner Column width = hasState ? lerp(minWidth, effectiveExpandedWidth, progress) : minWidth, where effectiveExpandedWidth = max(expandedWidth, minWidth). Column: verticalScroll (ScrollController), centerHorizontally, top arrangement, vertical padding = VerticalPadding(24). Children order: if state!=null → toggle button + Spacer(h=24); if header!=null → header() + Spacer(h=24); then content(). VerticalDivider drawn AFTER the Column (to the right) when showDivider (default true).

TOGGLE (only when state!=null): MiuixIconButton(minWidth=56, minHeight=56) containing the Sidebar icon sized 28, tint=colors.onSurfaceContainer, onPressed=state.toggle(). Its X morphs in a custom layout: collapsedX = (collapsedWidth(=minWidth 80).px - buttonW)/2; expandedX = ExpandedItemHorizontalMargin(12).px; x = round(lerp(collapsedX, expandedX, fraction)); placed within full available width, y=0. (At defaults these are near-coincident so it barely moves.)

CLASSIC ITEM (expandInfo==null): Column fillMaxWidth, selectable(ripple via LocalIndication) role=Tab, padding(vertical=ItemVerticalPadding=12), then badgeBounds() if badge!=null. Center alignment. Children: NavigationItemIcon(BadgedBox wrap) → Image(icon) size 28 tinted colors.onSurfaceContainer via ColorFilter.tint; Spacer(h=IconTextSpacing=4); Text(label) color=onSurfaceContainer, textAlign=center, fontSize=12, FontWeight.w500(Medium). NOTE: classic item has NO selection pill — selection is semantic + ripple only. tint is ALWAYS onSurfaceContainer regardless of `selected` (no selected/unselected color difference in this component).

EXPANDABLE ITEM (expandInfo!=null): a Box(fillMaxWidth, selectable role=Tab indication=null, badgeBounds if badge) wrapping a CustomMultiChildLayout with 3 children ids: "indicator","icon","label". Indicator = Box clipped to Rounded(16) squircle; squircleBackground(color=colors.surfaceContainerHigh, cornerRadius=16) ONLY when selected; carries the press indication(interactionSource). Icon = Image size 28 tinted onSurfaceContainer. Label leaf = MiuixText(maxLines:1, ellipsis, color=onSurfaceContainer, fontWeight w500, fontSize = lerp(12,16,fraction)).

EXPANDABLE LAYOUT MATH (fraction=progress 0..1, width=maxWidth, all lerp in float then round ONCE per coord). Constants in px: margin=12, leadingInset=14, expandedSpacing=16, topPad=12, collapsedSpacing=4, collapsedIndVPad=4, expandedVPad=14. Measure icon loose → iconW,iconH (28,28). Label maxWidth = lerp(width, expandedLabelMax, fraction) where expandedLabelMax = max(0, width - 2*margin - 2*leadingInset - iconW - expandedSpacing); measure label with that maxWidth, maxHeight=constraints.maxHeight → labelW,labelH. collapsedHeight = topPad + iconH + collapsedIndVPad*2 + collapsedSpacing + labelH + topPad. expandedHeight = expandedVPad*2 + max(iconH,labelH). height = round(lerp(collapsedHeight, expandedHeight, fraction)). collapsedIconX = (collapsedWidth.px - iconW)/2; expandedIconX = margin+leadingInset; iconX = round(lerp(collapsedIconX, expandedIconX, fraction)); iconY = round(lerp(topPad+collapsedIndVPad, (height-iconH)/2, fraction)). indicatorVPad = round(lerp(collapsedIndVPad, expandedVPad, fraction)); indicatorH = iconH + indicatorVPad*2; indicatorY = iconY - indicatorVPad; indicatorX = round(lerp(collapsedIconX - leadingInset, margin, fraction)); indicatorW = max(0, round(lerp(iconW+leadingInset*2, width-margin*2, fraction))); indicator measured with fixed(indicatorW,indicatorH). collapsedLabelY = topPad+iconH+collapsedIndVPad*2+collapsedSpacing; collapsedLabelX = collapsedIconX + iconW/2 - labelW/2; expandedLabelX = margin+leadingInset+iconW+expandedSpacing; labelX = max(0, round(lerp(collapsedLabelX, expandedLabelX, fraction))); labelY = round(lerp(collapsedLabelY, (height-labelH)/2, fraction)). Place order: indicator, icon, label. Use CustomMultiChildLayout + MultiChildLayoutDelegate; delegate.shouldRelayout on fraction change; feed fraction from AnimatedBuilder.

STATE: MiuixNavigationRailState as ChangeNotifier with `MiuixNavigationRailValue currentValue` (enum collapsed/expanded), `bool get isExpanded`, expand()/collapse()/toggle() calling notifyListeners. NavigationRail listens (AnimatedBuilder/ListenableBuilder) and drives the controller toward isExpanded. Provide a `rememberNavigationRailState`-equivalent as a plain constructor (skip Saver/process-death persistence; note in doc).

FontWeight.Medium → FontWeight.w500. Row `only(Start)` insets → left padding. Header receives ColumnScope in Kotlin (centered horizontally). File header comment per conventions; Chinese /// docs; one file components/miuix_navigation_rail.dart.</keyNotes>
