## 命名映射（强制）
- 组件 Widget：`Miuix<Name>`（如 `MiuixBadge`）。Kotlin 的 `Basic<X>` → `Miuix<X>` 或私有 `_Basic<X>`（内部用）。
- 颜色配置类：`Miuix<Name>Colors`，加 `@immutable`，全 `final` 字段，`const` 构造。
- 默认值类：`Miuix<Name>Defaults`，私有构造 `Miuix<Name>Defaults._();`，静态常量 + `static Miuix<Name>Colors defaultColors(BuildContext context)`（从 `MiuixTheme.of(context).colors` 取色）。
- 枚举：Kotlin enum → Dart `enum`，`MiuixXxxType` 命名。
- Kotlin `object XxxDefaults { val CornerRadius = 16.dp }` → `class MiuixXxxDefaults { MiuixXxxDefaults._(); static const double cornerRadius = 16; }`（dp→逻辑像素，直接用数值）。

## Compose → Flutter 机制映射（强制）
- `CompositionLocal` / `LocalContentColor` → `InheritedWidget`。内容色用现成的 `MiuixContentColor.of(context)` / `MiuixContentColor(color:, child:)`。
- `MiuixTheme.colorScheme.xxx` → `MiuixTheme.of(context).colors.xxx`。
- `MiuixTheme.textStyles.xxx` → `MiuixTheme.of(context).textStyles.xxx`（`TextStyle`，可 `.copyWith`；字号 `.fontSize`）。
- squircle 圆角 → `MiuixSquircleBorder(cornerRadius:, enabled: cornerRadius>0, side:)`，配 `ShapeDecoration(color:, shape:)`。裁剪用 `ClipPath(clipper:...)` 或对 `MiuixPressable` 传 `borderRadius`。
- 按压反馈（`Modifier.pressable` + `MiuixIndication` + Sink/Tilt）→ `MiuixPressable(onPressed:, feedbackType: MiuixPressFeedbackType.{none|sink|tilt}, borderRadius:, child:)`。
- `PressFeedbackType.{None,Sink,Tilt}` → `MiuixPressFeedbackType.{none,sink,tilt}`。
- spring 动画：用 `folmeSpring(damping:, response:)`（来自 `theme/miuix_motion.dart`）→ `SpringDescription`，配 `AnimationController.unbounded(vsync:)..animateWith(...)`。缓动曲线用 `MiuixMotion.{standardDecelerate,standardAccelerate,sinOut}` 或 `AccelerateEasing/DecelerateEasing/SinOutEasing`。
- `remember { MutableInteractionSource() }` + hover/focus/press → `MiuixPressable` 已内建；如需自管理状态用 `StatefulWidget`。
- `Modifier.clickable` 无涟漪 → `GestureDetector(onTap:)` 或 `MiuixPressable`。
- `Layout(...) { measurables, constraints -> }` 自定义测量 → `CustomMultiChildLayout` + `MultiChildLayoutDelegate`，或 `Row/Column/Flexible/Stack`（能用标准布局就用标准布局）。
- `Canvas`/`drawWithCache`/`Path` 绘制 → `CustomPainter` + `Canvas`/`Path`。
- `Popup`/`Dialog`/`Overlay`（`MiuixPopupUtils`、`overlay/`、`window/`）→ Flutter `Overlay` + `OverlayEntry`，或 `showGeneralDialog`/`OverlayPortal`。见下方"弹层基础设施"。
- `AnimatedVisibility` / `animate*AsState` → `AnimatedBuilder`/`TweenAnimationBuilder`/隐式动画组件。
- `LazyColumn`/`LazyRow` → `ListView.builder`/`SingleChildScrollView`。
- `rememberScrollState`/`ScrollableState` → `ScrollController`。
- `derivedStateOf`/`snapshotFlow` → 监听 controller/notifier 后 `setState` 或 `ValueListenableBuilder`。
- `Dp` → double（逻辑像素，1:1）。`sp` → 逻辑像素（Flutter 的 `fontSize` 单位）。`PaddingValues` → `EdgeInsets`。
- 图标：Compose `ImageVector`/`Icon` → 用 Flutter `Widget`（调用方传入）。`MiuixIcon` 组件接受 `Widget`/`IconData` 并用 `MiuixContentColor` 上色（tint）。
