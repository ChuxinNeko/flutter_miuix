## 平台/原生差异处理(platformConcerns)
BIGGEST ISSUE — NestedScrollConnection has NO Flutter equivalent. Compose intercepts and CONSUMES scroll deltas via onPreScroll/onPostScroll/onPreFling/onPostFling and negotiates a chain (TopAppBar behavior first when Idle, refresh first otherwise; Refreshing/RefreshComplete consume ALL scroll). Flutter's NotificationListener<ScrollNotification> is OBSERVE-ONLY (cannot consume). Recommended faithful port (mirrors Flutter's own RefreshIndicator): NotificationListener + OverscrollNotification (overscroll.overscroll<0 at top = pull-down → feed |delta| into currentTouch/applyDrag) + ScrollUpdateNotification + ScrollStartNotification, driving the growing header (which naturally displaces content, matching miuix's Column layout). Use ClampingScrollPhysics on the inner list so the top-edge pull is available as overscroll. To 'consume upward drag to hide the indicator' when dragOffset>0 (Compose onPreScroll available.y<0 path), gate with an active pull flag and, while dragOffset>0, absorb ScrollUpdate deltas into applyDrag before the list scrolls (may require a custom ScrollPhysics or intercepting via a Listener on pointer moves). Pointer-up detection → Listener(onPointerUp/onPointerCancel) since NotificationListener has no reliable release event.

OverScrollState/miuix custom overscroll (utils/Overscroll.kt) — separate un-ported infra; the isOverScrollActive gating and LocalPullToRefreshState provider exist only so miuix's own overscroll bypasses itself during refresh. The Dart project has no miuix overscroll (uses Flutter's built-in). Safe to DROP the overScrollState gating and the LocalPullToRefreshState CompositionLocal for a standalone port; note in a comment.

LocalWindowInfo.containerSize.height → MediaQuery.of(context).size.height or LayoutBuilder constraints.maxHeight. LocalDensity toPx/toDp → identity in Flutter (all logical px). withFrameNanos loop → AnimationController/Ticker. topAppBarScrollBehavior coordination → route scroll notifications through the already-ported MiuixScrollBehavior only while Idle (as Compose does). HapticFeedbackType.GestureThresholdActivate → HapticFeedback.selectionClick().

## 实现要点(keyNotes) — 严格按此复刻
NO theme tokens used — color is hardcoded Compose Color.Gray = Color(0xFF888888); refreshTextStyle is built inline (fontSize 14, FontWeight.bold, color=gray). No colorScheme/textStyles references at all.

DEFAULTS: refreshThreshold=0.25 (clamped 0..1); circleSize=20; color=0xFF888888; refreshTexts=["Pull down to refresh","Release to refresh","Refreshing...","Refreshed successfully"]; refreshTextStyle=TextStyle(fontSize:14, fontWeight:bold, color:gray). Constants MAX_DRAWRATIO=1/6, THRESHOLD_RADIO=1/4.

PIXEL/DP: Compose mixes px (via density) and dp. In Flutter EVERYTHING is logical px — drop all toPx/toDp; use container height directly. containerHeight H = MediaQuery/LayoutBuilder constraints.maxHeight. Derived (verbatim): maxDragDistance=H; fullDragRange=obtainDampingDistance(1,H)=H/3; refreshThresholdOffset=H*(1/6)*(1/4)=H/24 (fixed visual threshold); triggerProgressOffset=refreshThreshold*fullDragRange=0.25*H/3=H/12; effectiveThresholdOffset=max(H/24,H/12)=H/12 (denominator of pullProgress); visualProgress denominator scaleEndOffset=min(H/24,H/12)=H/24 (so scale-up completes at the SMALLER threshold). pullProgress=(dragOffset/effectiveThreshold).clamp(0,1); fullDragProgress=(dragOffset/fullDragRange).clamp(0,1); visualProgress=(dragOffset/scaleEnd).clamp(0,1).

DAMPING MATH (port verbatim from SpringUtils.kt): obtainDampingDistance(n,range): x=n.clamp(0,1); factor=x - x^2 + x^3/3; return factor*range. obtainTouchDistance(px,range): abs=|px| clamped to obtainDampingDistance(1,range); base=range-3*abs; return range - range^(2/3)*sign(base)*|base|^(1/3). Drag apply loop (onPost/PreScroll): currentTouch+=delta, clamp(-H,H); normalized=min(|currentTouch|/H,1); dragOffset=sign(currentTouch)*obtainDampingDistance(normalized,H). State from dragOffset: >=triggerProgressOffset→ThresholdReached; >0→Pulling; else Idle.

SPRING: SpringEngine = critical damping ratio 1.0, naturalPeriod 0.4s standard (0.55s only if |initialVel|>5000 — never hit here, all animateToSpring calls start vel=0). Euler integrate: ω=2π/period, k/m=ω², c/m=2*ζ*ω; v = v*(1-c/m*dt)+k/m*(target-pos)*dt; pos+=dt*v; dt clamped [0.001,0.016]; settle when |pos-target|<1.0. FAITHFUL FLUTTER: AnimationController.unbounded(vsync).animateWith(SpringSimulation(folmeSpring(damping:1.0,response:0.4), start,target,0)) — same pattern as miuix_top_app_bar _SpringSimulation. Each animation frame you MUST also update currentTouch=obtainTouchDistance(dragOffset,H) so a mid-flight catch stays visually consistent. animateToSpring cancels any prior job first. For pixel-exact fidelity you may instead port the Euler loop with a Ticker, but folmeSpring is acceptable.

STATE MACHINE (5 states) + hoisted two-way isRefreshing sync: (1) rising edge isRefreshing=true while Idle → showRefreshing: set Refreshing, animateToSpring(H/24), then a while-loop re-chases the target if H/24 moved (covers first-frame H unknown). (2) isRefreshing=false while Refreshing → finishRefreshing: cancel anim job, set RefreshComplete, run completion anim. (3) pointer release (Pulling/ThresholdReached + all pointers up) → handlePointerRelease: if dragOffset>=triggerProgressOffset → startRefreshing (spring to H/24, then Refreshing + fire onRefresh only if not already refreshing), else rebound animateToSpring(0)→resetToIdle. Guards isProcessingRelease/isTouching/isRebounding must be replicated. Completion anim (startManualRefreshCompleteAnimation): Animatable initial=1-(dragOffset/H24).clamp(0,1); tween 200ms Cubic(0,0,0,0.37) to 1; each frame dragOffset=H24*(1-value), then set Idle. onRefresh must be called AFTER internalRefreshState=Refreshing (ordering guards the lost-pulse latch). Pointer-release detection: Compose awaitPointerEvent → Flutter Listener(onPointerUp/onPointerCancel).

LAYOUT: Box>Column[ RefreshHeader (offset y = contentPadding.top), content() ]. Header pushes content down as it grows (both in Column). RefreshHeader = Column(fillMaxWidth, height=headerHeight, CenterHorizontally, top): [RefreshIndicator height=indicatorHeight, Text(top padding 6, alpha=refreshTextAlpha)]. stretchExtra = dragOffset - H/24 (negative during scale phase). indicatorHeight: Idle→0; stretchExtra<=0 → circleSize*visualProgress; else circleSize+stretchExtra. headerHeight: Idle→0; stretchExtra<=0 → (circleSize+36)*visualProgress; else (circleSize+36)+stretchExtra.

TEXT per state: Idle""; Pulling→texts[0] only if visualProgress>0.5; ThresholdReached→texts[1]; Refreshing→texts[2]; RefreshComplete→texts[3]. refreshTextAlpha: Idle 0; Pulling (progress>0.6 ? (progress-0.5)*2 : 0); ThresholdReached 1; Refreshing ((visualProgress-0.5)*2).clamp(0,1); RefreshComplete (1 - completeProgress*1.95).clamp(min 0).

CANVAS (size=circleSize=20 box, TopCenter): ringStrokeWidth=circleSize/11≈1.818; radius=max(size.minDimension/2, circleSize/3.5)=max(10,5.71)=10; center=Offset(circleSize/2=10, circleSize/1.8≈11.11). Draw modes: Pulling & dragOffset<=threshold → drawCircle(stroke round, alpha=(visualProgress-0.2).clamp(min0)). Pulling/ThresholdReached & dragOffset>threshold → drawThresholdIndicator: capsule = arc(180°,sweep180 top-half at center.y) + arc(0°,sweep180 bottom-half at center.y+lineLength) + two vertical lines at x=center.x±radius from topY to bottomY; lineLength=(dragOffset-threshold).clamp(0, maxDrag-threshold); all Stroke round. Refreshing → drawCircle full ring + orbiting dot: orbitRadius=radius-2*strokeWidth≈6.36, angle=rotation*π/180, dot at center+(orbit*cos,orbit*sin), dot filled radius=strokeWidth; ring color premultiplied by expansionAlpha=((visualProgress-0.2)/0.8).clamp(0,1). RefreshComplete → drawCircle stroke, animatedRadius=radius*(1-progress).clamp(min 0.9), alpha=(1-progress-0.35).clamp(min0), y=center.y-radius-strokeWidth+animatedRadius.

ROTATION: only while Refreshing. infiniteRepeatable tween 800ms LinearEasing, Restart, initialValue=random(0..360), sweeps +360. Flutter: AnimationController(duration:800ms)..repeat(), Curves.linear, add random start offset.

HAPTIC: on entering ThresholdReached → HapticFeedbackType.GestureThresholdActivate → Flutter HapticFeedback.selectionClick() (closest; or lightImpact).

onPullProgress(fullDragProgress) callback: fire once on init then on every change (drive from controller listener/ValueNotifier).
