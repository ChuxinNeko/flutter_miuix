# 移植分析：ColorPicker

- 复杂度: very-high
- 预估行数: 800
- 未移植依赖(unportedDeps): 无
- 已移植依赖(portedDeps): MiuixSliderHapticEffect (miuix_slider.dart enum: none/edge/step), MiuixSliderDefaults.defaultHapticEffect (== edge)
- 计划公开 API(publicApi): MiuixColorPicker (widget), MiuixColorSpace (enum: hsv, okhsv, oklab, oklch), MiuixHsvColorPicker, MiuixOkHsvColorPicker, MiuixOkLabColorPicker, MiuixOkLchColorPicker, companion color-math (separate file): MiuixHsv, MiuixOkHsv, MiuixOkLab, MiuixOkLch data classes; MiuixColorTransforms (Transforms port); Color extensions toMiuixHsv()/toMiuixOkLab()/toMiuixOkLch()
- 新增颜色 token: 无
- 新增文本样式: 无

## 平台/原生差异处理(platformConcerns)
Haptics: Kotlin LocalHapticFeedback.performHapticFeedback -> Flutter HapticFeedback.selectionClick() from services.dart (same approach the ported slider already uses); acceptable 1:1. No blur/sensors/tilt involved. BIGGEST concern is pure math, not native: OkLab/OkHsv/OkLch have NO Flutter/Dart stdlib equivalent, so the entire Transforms object + space classes + extensions must be ported by hand (verbatim matrix constants and toe/cusp/max-saturation code). Dart lacks cbrt — provide a signed cube-root helper (pow(|x|,1/3) with sign). Compose Brush.horizontalGradient with pixel startX/endX + TileMode.Clamp maps to ui.Gradient.linear(Offset(13,0),Offset(w-13,0),colors,null,TileMode.clamp) inside a CustomPainter (not a gradient BoxDecoration, because the inset is absolute px and edges must clamp). CircleShape here means a stadium/capsule (radius=height/2=13), NOT MiuixSquircleBorder — do not substitute squircle. Two-way color binding (SideEffect/derivedStateOf) -> compare ARGB ints in didUpdateWidget to avoid feedback loops.

## 实现要点(keyNotes) — 严格按此复刻
NO dependency on any of the 20 unported components and NO popup/overlay/theme-token usage at all — every color is hardcoded, so it can be ported now. THE REAL WORK is a companion color-math port (no Flutter equivalent exists for OkLab/OkHsv/OkLch): port ALL of Transforms.kt (~490 lines: rgb<->OkLab matrix constants verbatim, okLabToOklch/oklchToOkLab, rgbToHsv, srgbToOkhsv/okhsvToSrgb with toe()/toeInv() k1=0.206 k2=0.03 k3=(1+k1)/(1+k2), computeMaxSaturation red/green/blue coefficient tables, findCusp, getSTMax, srgbTransferFunction/Inv, generateHsvHueColors/generateOkHsvHueColors steps=36, generateOkLchHueColors(l,c,steps=36) with its rounded-key cache, normalizeOklch) PLUS the four space classes (Hsv/OkHsv/OkLab/OkLch .toColor with their coerce/normalize) and Color extensions toHsv/toOkLab/toOkLch (with the /0.4*100 remaps). Dart has no cbrt: use helper `x<0? -pow(-x,1/3) : pow(x,1/3)`. HSV path MAY reuse Flutter HSVColor (equivalent standard algorithm) but for 1:1 replicate rgbToHsv incl. the `(channel*255).toInt()` truncation. Estimate ~500 extra lines for math in a separate file (foundation/ or new color/ dir); the ~800 above is miuix_color_picker.dart alone.

STRUCTURE: MiuixColorPicker dispatches on MiuixColorSpace to 4 sub-pickers. Each sub-picker is a StatefulWidget holding channel floats + alpha + lastAppliedExternalArgb. TWO-WAY BINDING (SideEffect+derivedStateOf): selectedColor = space(channels).toColor(alpha). On external color change: externalArgb=widget.color.toARGB32(), internalArgb=selectedColor.toARGB32(); if externalArgb!=lastApplied && externalArgb!=internalArgb -> resync channels from widget.color, lastApplied=externalArgb. Map this to didUpdateWidget. notify: if selectedColor.toARGB32()!=widget.color.toARGB32() call onColorChanged. Init channels once from widget.color in initState.

LAYOUT: Column, verticalArrangement spacedBy 12 (SizedBox(height:12) between children). If showPreview: full-width Box height 26 clipped to STADIUM (radius=13, use ClipRRect/StadiumBorder — NOT squircle; Kotlin uses CircleShape) filled with selectedColor. Then 4 ColorSliders (each fillMaxWidth). HSV order: hue,sat,value,alpha. OkHSV: hue,sat,value,alpha. OkLab: L, A-channel, B-channel, alpha. OkLch: hue, lightness, chroma, alpha. Alpha sliders add drawCheckerboard behind.

Per-channel slider gradient color lists (2 colors unless noted, evenly spaced -> ui.Gradient.linear with null stops): HSV hue=36 colors; HSV sat=[Hsv(h,0,100),Hsv(h,100,100)]; HSV value=[Black, Hsv(h,s*100,100)]; HSV alpha=[base@0, base@1]. OkHSV hue=36; sat=[okhsv(h,0,1,1),okhsv(h,1,1,1)]; value=[okhsv(h,s,0,1),okhsv(h,s,1,1)]; alpha=[base@0,base@1]. OkLab L=8 colors (steps=7, i/7); A-channel=9 colors (minA=-0.3,maxA=0.3,steps=8) and slider value=(currentA+0.3)/0.6, onChanged maps normalized*0.6-0.3; B-channel same with B; alpha=[base@0,base@1]. OkLch: hue=generateOkLchHueColors (36); lightness=[oklch(0,c*0.4,h*360),oklch(1,...)]; chroma=[oklch(l,0,h),oklch(l,0.4,h)]; alpha=[opaque with a=0, opaque]. Note internal scaling: OkLab picker stores a,b as (raw/100)*0.4 and unmaps /0.4*100; OkLch stores c as 0..1 (=*0.4 internal), h as 0..1 (=*360).

ColorSlider (private, generic) — replicate exactly: indicatorSize=20, sliderHeight=26, halfSlider=13. Clip whole thing to STADIUM(radius=13). Draw via CustomPainter (drawWithCache equivalent): for alpha sliders draw checkerboard first, then gradient. Gradient = ui.Gradient.linear(Offset(13,0), Offset(width-13,0), colors[, RTL reversed], stops=null, TileMode.clamp). Then stroke bounding rect: Stroke width 0.5, color = const Color(0xFF888888).withValues(alpha:0.1) (Compose Gray@0.1). Indicator is a separate 20x20 child positioned so its CENTER x = value*(width-26)+13 (left = center-10); align center-vertically. Indicator painter: strokeWidth=6, halfStroke=3, glowSpread=2, glowColor=Black@0.25; ringCenterRadius=(20/2)-3=7; gradientRadius=7+3+2=12; radialGradient stops [(2/12)->transparent,(4/12)->glow,(10/12)->glow,(12/12)->transparent] radius=12; draw glow circle radius=12 then white ring: drawCircle white radius=7 Stroke(6). 

INTERACTION: use onHorizontalDragStart/Update/End ONLY (Kotlin uses draggable, NO tap-to-jump — do not add tap jump for fidelity). onDragStart: x=localPos.dx (RTL: width-x), dragOffset=x, value=handleSliderInteraction(x,width,26).clamp(0,1), notify, haptic.reset(value,0,1,prev). onDragUpdate: d=delta.dx (RTL negate), dragOffset+=d, value=handleSliderInteraction(dragOffset,width,26).clamp, notify, haptic.handleHapticFeedback(value,0,1,effect,[]). handleSliderInteraction: half=13, eff=width-26, cx=x.clamp(13,width-13), return ((cx-13)/eff).clamp(0,1). Track width via LayoutBuilder.constraints.maxWidth. RTL via Directionality.of(context).

HAPTICS: ported _SliderHapticState in miuix_slider.dart is PRIVATE — cannot import. Reimplement a tiny local haptic-state (reset + handleHapticFeedback with min=0,max=1, empty keyPoints, hasCustomKeyPoints=false) using HapticFeedback.selectionClick() (services.dart). With default effect=edge this only fires at value==0 or ==1.

drawCheckerboard: cell=3 (>=1px), lightColor=const Color(0xFFCCCCCC), darkColor=const Color(0xFFAAAAAA). rows=ceil(h/3).clamp(>=1) (=9 at h=26). Fill light rect; then dark squares: per row start x=(row even? cell:0), addRect(x,y,min(x+cell,w),min(y+cell,h)), x+=cell*2, y+=cell -> checkerboard. Draw in same painter behind the alpha gradient.

Use .toARGB32() (not deprecated .value) for all ARGB int comparisons; use color.withValues(alpha:) (not withOpacity) for copy(alpha=). Recommend keeping the 16 per-channel slider wrapper composables PRIVATE (their Kotlin publicness is incidental); expose only MiuixColorPicker + 4 sub-pickers + MiuixColorSpace.
